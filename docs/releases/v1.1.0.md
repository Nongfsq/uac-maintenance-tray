# UAC Maintenance Tray v1.1.0

## Highlights

- Added live tray-language selection: Follow Windows language, English, and Simplified Chinese.
- Added external, auditable UTF-8 JSON language packs with embedded English fallback.
- Persisted language preference per Windows user without requiring elevation.
- Localized status text, confirmation warnings, busy states, and elevation failures.
- Added active language and runtime information to file diagnostics.
- Continued dual distribution: framework-dependent and self-contained single-EXE packages.
- Updated the self-contained package to .NET 10.0.10 security servicing.

## 中文摘要

- 托盘菜单新增“跟随 Windows 语言、English、简体中文”实时切换。
- 新增可审计的 UTF-8 JSON 语言包，并保留内置英文兜底。
- 语言选择按 Windows 用户保存，无需管理员权限。
- 状态、风险确认、等待提示和提升失败信息均已本地化。
- 继续提供依赖运行时版和自包含版两个单 EXE 发布包。

## Install

The smaller `framework-dependent` package is recommended and requires the latest .NET 10 Desktop Runtime x64. Use `self-contained` when installing .NET is not possible. Verify either ZIP with the accompanying `UacMaintenanceTray-v1.1.0-SHA256SUMS.txt`.
